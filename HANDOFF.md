# HANDOFF — сайт shugaringtyt.ru

Одностраничный сайт мастера по шугарингу (Мытищи). Статика: HTML + CSS + JS, без сборки.
Этот файл описывает, что где настроено, чтобы продолжить работу без истории переписки.

## Как обновить сайт

```bash
git add -A && git commit -m "..." && git push
```

GitHub Pages пересобирается сам (около минуты). Проверка статуса: `gh api repos/Hofmann88/shugaringtyt-ru/pages --jq .status` (`built` = готово).
Локальный просмотр: `python3 -m http.server 8934` в корне репозитория, открыть http://localhost:8934.

## Форма записи → Google Таблица

Поля: имя, телефон (маска +7), услуга (select), желаемая дата, комментарий, согласие.
Отправка: `fetch(POST, mode:"no-cors", Content-Type: text/plain)` с JSON на `GOOGLE_SCRIPT_URL`.
Скрипт пишет строку: A — дата и время (формат `dd.MM.yyyy HH:mm:ss`), B–G — текст (формат `@`), чтобы `+7 ...` не превращался в формулу (`#ERROR!`).

Изменили `Code.gs` → в Apps Script: **Развернуть → Управление развёртываниями → ✏️ → Новая версия → Развернуть**. URL остаётся прежним.
Доступ развёртывания: выполнять как «я», доступ «Все».

Проверка из терминала (не добавляйте `-X POST`, иначе curl сломает редирект Google):

```bash
curl -sL "<GOOGLE_SCRIPT_URL>" -H "Content-Type: text/plain;charset=utf-8" \
  -d '{"name":"Тест","phone":"+7 (900) 000-00-00","service":"Тест","date":"","comment":"","page":"test"}'
# ожидаемый ответ: {"ok":true}
```

1. Яндекс.Метрика: завести счётчик, прислать код, вставить перед `</head>`/в конец `<body>`.

3. Добавить организацию в Яндекс Бизнес / 2ГИС / Google Business Profile (влияет на локальную выдачу).
4. Поставить реальные фото мастера и студии.
5. Старый сайт лежит в соседней папке проекта (вне репозитория) и больше не используется.
