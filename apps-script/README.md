# Подключение формы к Google Таблице

Заявки с сайта нужно доставить в вашу таблицу:
https://docs.google.com/spreadsheets/d/1YwJYPSZZvRVURj2_Lovta4qrhbJ9yeHfCe9wdfBJM0g/edit

Это делается через Google Apps Script — бесплатный скрипт, который живёт прямо
внутри таблицы и принимает данные с сайта. Ниже пошагово, займёт 3–5 минут.

## Шаг 1. Откройте редактор скриптов

1. Откройте вашу таблицу по ссылке выше.
2. Меню **Расширения → Apps Script**.
3. Откроется редактор с файлом `Code.gs` (может быть пустой шаблон `myFunction`).

## Шаг 2. Вставьте код

1. Удалите всё содержимое файла `Code.gs` в редакторе.
2. Скопируйте в него содержимое файла [`Code.gs`](./Code.gs) из этой папки.
3. Нажмите значок дискеты (Сохранить проект). Можно дать проекту имя,
   например «Заявки с сайта».

## Шаг 3. Опубликуйте как веб-приложение

1. Справа сверху нажмите **Развернуть → Новое развёртывание** (Deploy → New deployment).
2. Рядом с «Выберите тип» нажмите на шестерёнку → **Веб-приложение** (Web app).
3. Настройки:
   - **Execute as (Выполнять как):** я (ваш аккаунт)
   - **Who has access (У кого есть доступ):** Все (Anyone)
4. Нажмите **Развернуть**.
5. Google попросит авторизовать доступ — это ваш собственный скрипт к вашей
   же таблице, нажмите **Разрешить** (может появиться предупреждение
   «Google не проверил это приложение» — это нормально для личных скриптов,
   нажмите «Дополнительно» → «Перейти на страницу (небезопасно)»).
6. После публикации Google покажет **URL веб-приложения** вида:
   `https://script.google.com/macros/s/AKfycbx.../exec`
   Скопируйте его целиком.

## Шаг 4. Вставьте URL на сайт

Откройте файл [`../js/config.js`](../js/config.js) и замените значение на
скопированный URL:

```js
window.SITE_CONFIG = {
  GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/AKfycbx.../exec"
};
```

Сохраните файл — форма на сайте сразу начнёт писать заявки в лист «Заявки»
вашей таблицы (лист создастся автоматически при первой заявке).

## Если понадобится изменить скрипт

После любого изменения кода в `Code.gs` нужно создать **новое развёртывание**
(Развернуть → Управление развёртываниями → значок карандаша → Новая версия →
Развернуть), иначе изменения не применятся к уже опубликованному URL.

## Проверка

Отправьте тестовую заявку через форму на сайте — новая строка должна
появиться в листе «Заявки» в течение нескольких секунд.
